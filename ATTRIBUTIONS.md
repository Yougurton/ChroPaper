# Attributions

## Code and data

* [ChroViewer](https://github.com/Umbranoxio/chroviewer) by Umbranoxio and contributors
([GPL-2.0-only](LICENSE)). ChroPaper is a fork of ChroViewer adapted for Wallpaper Engine by Yougurton.
* [ChroMapper](https://github.com/Caeden117/ChroMapper) by Caeden117 and contributors
([GPL-2.0](LICENSE)). The environment data in `public/environments/`, preview math, shaders,
materials and lighting code come from ChroMapper through ChroViewer.
